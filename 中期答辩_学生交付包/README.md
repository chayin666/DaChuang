# 中期答辩材料

已把22页初稿重组为四章12页主讲稿，计划6分40秒。每页固定为“上部文字（为什么）—中部证据—下部文字（结论）”，面向不一定熟悉人工智能的老师讲清项目状态。分割比较、有限元案例和TRIPLEX复现/消融结果已直接放入阶段结果页，完整比较表留作备份。原Word及项目源文件保持不变。本文件夹为学生制作中期答辩PPT的交付包，已将大纲、素材和必要说明集中整理。

## 四章结构

| 章节 | 页码 | 内容重点 |
| --- | --- | --- |
| 第一章 项目目标与中期进度 | 1—3 | 项目身份、研究问题、申报任务与实际进度 |
| 第二章 阶段实验结果 | 4—6 | 组织分割、候选力学表征、基线复现与对照 |
| 第三章 项目衔接与待验证任务 | 7—9 | PathAgent适配、关键基因预测验证、问题闭环 |
| 第四章 后续计划与项目管理 | 10—12 | 交付节点、团队贡献、经费和中期结论 |

中期答辩的目标是让老师判断项目是否真实推进、证据是否可核验、问题是否清楚、后续是否可完成。主稿不增加独立目录页，用页眉或色带显示章节导航。

## 使用顺序

1. [优化后的逐页PPT大纲](02_中期答辩PPT大纲_优化版.md)：包括上部文字、中部证据、下部结论、讲述要点、配图及时间安排。按此稿制作和排练。
2. [初稿问题与修改建议](01_初稿问题与修改建议.md)：解释结构、任务对应、时间和技术表述的修改。
3. [补充实验结果与待补清单](03_补充实验结果与待补清单.md)：完整指标、实验规模、素材链接、答辩追问及文件来源。
4. [学生Word大纲转Markdown](原文转换/学生大纲_原文.md)：原文转录，便于对照。
